# บันทึกผลการออกตรวจงานจ้าง (InspectDocx)

เว็บแอปทำ "บันทึกข้อความรายงานผลการออกตรวจงานจ้าง + บันทึกผลการตรวจงานจ้าง" ของคณะกรรมการตรวจรับพัสดุ
กรอกข้อมูลในหน้าเว็บ → กดปุ่มเดียวได้ไฟล์ Word (.docx) ตามแบบฟอร์มเดิม

**เปิดใช้งาน:** https://dstaokung.github.io/InspectDocx/ (หลัง publish ขึ้น GitHub Pages แล้ว) — v1.2

## วิธีใช้

1. กรอก **โครงการ / สัญญาจ้าง** และ **คณะกรรมการ** (กรอกครั้งเดียวต่อโครงการ)
2. กรอก **การออกตรวจครั้งนี้** — ครั้งที่, วันที่, เวลา, ผลการตรวจ
3. ใส่ **รูปถ่าย** 4 ช่อง (คลิก/ลากวาง/เลือกหลายรูปพร้อมกัน, หมุน, ย้ายช่องได้) — ตัดขอบพอดีกรอบให้เอง
4. กด **สร้างไฟล์ .docx** → ได้ไฟล์ทันที
5. กด **บันทึก/อัปเดต** เพื่อเก็บโครงการไว้ ครั้งหน้าเลือกโครงการ → กด **ออกตรวจครั้งถัดไป**
   (ครั้งที่ +1 และล้างเฉพาะวันที่/เวลา/ผลการตรวจ/รูป)

- ช่องวันที่ **เลือก** วัน / เดือน / ปี พ.ศ. จากรายการ (กันพิมพ์ผิด) มีปุ่ม **วันนี้** และ **✕** ล้างช่อง — ในเอกสารออกเป็น `5 กันยายน 2568`
- ช่องเวลาพิมพ์ `9` หรือ `9.30` → `09.00` / `09.30` · วงเงินพิมพ์ `4867000` → `4,867,000.00` + ตัวอักษรให้เอง
- **คำนำหน้า/ยศ** (เช่น ว่าที่ร้อยตรี) ไม่มีก็ปล่อยว่าง — เอกสารจะว่างไว้ตรงนั้น
- ช่องที่ไม่ได้กรอก จะออกเป็น `......` ตัวอักษรสีแดงในไฟล์ ให้เห็นว่าต้องแก้
- รูปถ่ายไม่ถูกจำไว้ ปิดหน้าเว็บแล้วต้องใส่ใหม่ · ไม่ใส่รูปเลย เอกสารจะคงกรอบ SmartArt เดิมไว้
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น (ไม่ส่งขึ้นเซิร์ฟเวอร์) — ย้ายเครื่องใช้ปุ่ม **สำรองข้อมูล / นำเข้า**
- เปิดใช้แบบออฟไลน์ได้ โดยดับเบิลคลิก `index.html` ในโฟลเดอร์นี้

## โครงสร้าง repo

| ตำแหน่ง | หน้าที่ |
|---|---|
| `index.html` | หน้าโปรแกรมทั้งหมด (ฟอร์ม + ปุ่มสร้างไฟล์ + บันทึกโครงการ) |
| `shared/docgen.js` | ตัวเติม placeholder ลง .docx + ตัวแปลงวันที่/เวลา/เงิน + `buildFields()` (ผูกช่องฟอร์ม → placeholder) |
| `template-data.js` | เทมเพลต .docx ในรูป base64 — สร้างด้วย `tools/gen-template-data.py` ห้ามแก้มือ |
| `templates/บันทึกออกตรวจงานจ้าง_template.docx` | ไฟล์ Word ต้นแบบ (มี `[placeholder]`) |
| `PLACEHOLDERS.md` | **คู่มือ placeholder ทั้งหมด + วิธีเพิ่มใหม่** |
| `tools/gen-template-data.py` | `python tools/gen-template-data.py` — ต้องรันทุกครั้งที่แก้เทมเพลต |
| `tools/fixtures/` | รูปทดสอบ 3 รูปสำหรับ test-build.js |
| `tools/test-build.js` | `node tools/test-build.js` — ทดสอบสร้างไฟล์ เช็คว่าไม่มี placeholder ค้าง |
| `shared/jszip.lib.js`, `monthyear.js`, `theme.js` | ไลบรารีชุดเดียวกับ ConsDocx (JSZip, เดือน/ปีไทย, โทนสี) |

## อัปเดตขึ้น GitHub (GitHub Desktop)

ครั้งแรก:
1. GitHub Desktop → **File → Add local repository** → เลือกโฟลเดอร์ `D:\ClaudeCowork\ออกตรวจงาน\InspectDocx`
   → ขึ้นว่ายังไม่ใช่ repository ให้กด **create a repository** (Name: `InspectDocx`) → Create
2. กด **Publish repository** — เอาติ๊ก "Keep this code private" ออก (GitHub Pages ฟรีต้องเป็น public)
3. เข้า github.com → repo `InspectDocx` → **Settings → Pages** → Source: *Deploy from a branch*,
   Branch: `main` / `(root)` → Save → รอ 1–2 นาที ได้ลิงก์ `https://dstaokung.github.io/InspectDocx/`

ครั้งต่อไป: เปิด GitHub Desktop → **Commit to main** → **Push origin** → เว็บอัปเดตเองในไม่กี่นาที
